# Application Formats

Read only the section for the selected document type. User-provided limits override the defaults below.

## Cover letter

Required inputs: target role, company, and job description or known role requirements. Use a default length of 500 to 800 words when the application provides no limit.

Structure:

1. Open with the application purpose and a specific, truthful connection to the work, field, or product when one exists. Otherwise lead with the strongest role-relevant evidence.
2. Show product or business judgment through one concrete result.
3. Develop one recent core project: the challenge, strategic choices, constraints, leadership, and verified outcome.
4. Close with the value the candidate can bring and a direct next step.

Weave company fit into the opening or closing instead of adding a generic praise paragraph.

## Job-application answer

Required inputs: the exact question, target role, company, and stated limit. Use a default length of 150 to 400 words when the application provides no limit.

Answer the question in the first sentence. Use the strongest single example, organized around situation, responsibility, action, and result. Close by connecting the evidence to the competency behind the question.

## Interview self-introduction

Required inputs: target role and speaking-time limit. Ask for the company and job description when they would materially change the emphasis.

Open with the candidate's current professional identity. Connect one or two recent experiences into a role-relevant arc, then close with the value the candidate wants to bring. Write for natural speech and fit the requested duration; avoid a chronological resume recital.

## Recruiter response

Required inputs: the recruiter's message and the user's intended answer. Request resume evidence only when the response makes claims about candidate experience.

Answer the recruiter's question or request immediately. Include only the context needed to prevent ambiguity, state availability or the next action clearly, and add an appropriate greeting and sign-off when the channel calls for them.
